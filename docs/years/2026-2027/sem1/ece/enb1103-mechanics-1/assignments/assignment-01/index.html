2 Problem Set

2.1 Problem 1 (Lecture Problem 5)

Two cables exert forces \(F_B = 600\text{ lb}\) and \(F_C = 750\text{ lb}\) on the hook at \(A(0, 0, 4\text{ ft})\), anchored at \(B(3\text{ ft}, -3\text{ ft}, 2.5\text{ ft})\) and \(C(2\text{ ft}, 4\text{ ft}, 0\text{ ft})\)[cite: 20]. Determine the magnitude and coordinate direction angles of the resultant force acting at \(A\)[cite: 20].

TipSolution Key — Problem 1 (Lecture Problem 5)
  • \(\mathbf{r}_{AB} = 3\mathbf{i} - 3\mathbf{j} - 1.5\mathbf{k}\text{ ft}, \quad |\mathbf{r}_{AB}| = 4.5\text{ ft} \implies \mathbf{F}_B = 600\left(\frac{3\mathbf{i} - 3\mathbf{j} - 1.5\mathbf{k}}{4.5}\right) = \{400\mathbf{i} - 400\mathbf{j} - 200\mathbf{k}\}\text{ lb}\)
  • \(\mathbf{r}_{AC} = 2\mathbf{i} + 4\mathbf{j} - 4\mathbf{k}\text{ ft}, \quad |\mathbf{r}_{AC}| = 6\text{ ft} \implies \mathbf{F}_C = 750\left(\frac{2\mathbf{i} + 4\mathbf{j} - 4\mathbf{k}}{6}\right) = \{250\mathbf{i} + 500\mathbf{j} - 500\mathbf{k}\}\text{ lb}\)
  • \(\mathbf{F}_R = \mathbf{F}_B + \mathbf{F}_C = \{650\mathbf{i} + 100\mathbf{j} - 700\mathbf{k}\}\text{ lb}\)
  • \(F_R = \sqrt{650^2 + 100^2 + (-700)^2} = 960.5\text{ lb}\)
  • \(\alpha = 47.4^\circ, \quad \beta = 84.0^\circ, \quad \gamma = 136.8^\circ\)

2.2 Problem 2 (Lecture Problem 6)

Two cables attached to ring \(A(0, -2\text{ m}, 4\text{ m})\) carry tensions of \(600\text{ N}\) (directed toward \(B(0, 0, 0)\)) and \(500\text{ N}\) (directed toward \(C\), located at \(x_C = 4\text{ m}\) and \(8\text{ m}\) in the \(+y\) direction from \(A\), i.e., \(C(4\text{ m}, 6\text{ m}, 0)\))[cite: 20]. Determine the magnitude and the coordinate direction angles of the resultant force[cite: 20].

TipSolution Key — Problem 2 (Lecture Problem 6)
  • \(\mathbf{r}_{AB} = 0\mathbf{i} + 2\mathbf{j} - 4\mathbf{k}\text{ m}, \quad |\mathbf{r}_{AB}| = \sqrt{20} = 4.472\text{ m} \implies \mathbf{F}_{AB} = \{268.33\mathbf{j} - 536.66\mathbf{k}\}\text{ N}\)
  • \(\mathbf{r}_{AC} = 4\mathbf{i} + 8\mathbf{j} - 4\mathbf{k}\text{ m}, \quad |\mathbf{r}_{AC}| = \sqrt{96} = 9.798\text{ m} \implies \mathbf{F}_{AC} = \{204.12\mathbf{i} + 408.25\mathbf{j} - 204.12\mathbf{k}\}\text{ N}\)
  • \(\mathbf{F}_R = \{204.12\mathbf{i} + 676.58\mathbf{j} - 740.78\mathbf{k}\}\text{ N}\)
  • \(F_R = 1024\text{ N}, \quad \alpha = 78.5^\circ, \quad \beta = 48.6^\circ, \quad \gamma = 136.3^\circ\)

2.3 Problem 3 (Lecture Problem 7)

A rifle at \(A\) (\(z_A = 80\text{ m}\)) is fired at a target at \(B\) Across a range with horizontal offsets \(\Delta x = 160\text{ m}\), \(\Delta y = 210\text{ m}\), and \(\Delta z = -80\text{ m}\)[cite: 21]. If the speed of the bullet is \(1800\text{ m/s}\), determine the rectangular form of the velocity vector \(\mathbf{v}\)[cite: 21].

TipSolution Key — Problem 3 (Lecture Problem 7)
  • \(\mathbf{r}_{AB} = 160\mathbf{i} + 210\mathbf{j} - 80\mathbf{k}\text{ m} \quad (\text{or } -160\mathbf{i} + 210\mathbf{j} - 80\mathbf{k}\text{ m depending on origin choice})\)
  • \(|\mathbf{r}_{AB}| = \sqrt{160^2 + 210^2 + (-80)^2} = \sqrt{76100} = 275.86\text{ m}\)
  • \(\mathbf{v} = 1800\frac{\mathbf{r}_{AB}}{|\mathbf{r}_{AB}|} = \{1044\mathbf{i} + 1370\mathbf{j} - 522\mathbf{k}\}\text{ m/s}\)

2.4 Problem 4 (Lecture Problem 8)

The slider travels along the guide rod \(AB\) from \(A(10\text{ m}, -8\text{ m}, 0)\) to \(B(0, 16\text{ m}, 12\text{ m})\) with a velocity \(v = 6\text{ m/s}\)[cite: 21]. Determine the rectangular representations of (a) the unit vector directed from \(A\) toward \(B\); and (b) the velocity vector \(\mathbf{v}\)[cite: 21].

TipSolution Key — Problem 4 (Lecture Problem 8)
  • \(\mathbf{r}_{AB} = (0 - 10)\mathbf{i} + (16 - (-8))\mathbf{j} + (12 - 0)\mathbf{k} = -10\mathbf{i} + 24\mathbf{j} + 12\mathbf{k}\text{ m}\)
  • \(|\mathbf{r}_{AB}| = \sqrt{(-10)^2 + 24^2 + 12^2} = \sqrt{820} = 28.636\text{ m}\)
  • (a) \(\mathbf{u}_{AB} = -0.349\mathbf{i} + 0.838\mathbf{j} + 0.419\mathbf{k}\)
  • (b) \(\mathbf{v} = 6\mathbf{u}_{AB} = \{-2.10\mathbf{i} + 5.03\mathbf{j} + 2.51\mathbf{k}\}\text{ m/s}\)

2.5 Problem 5 (Lecture Problem 9)

Two cables attached to the top of post \(C(0, 0, 4\text{ ft})\) exert forces \(F_1 = 100\text{ lb}\) (toward \(A\), located in the \(xy\)-plane at radius \(3\text{ ft}\) and angle \(40^\circ\) from the \(+y\) axis toward the \(-x\) axis) and \(F_2 = 81\text{ lb}\) (toward \(B(4\text{ ft}, -7\text{ ft}, 0)\))[cite: 22]. Determine the magnitude and the coordinate direction angles of the resultant force[cite: 22].

TipSolution Key — Problem 5 (Lecture Problem 9)
  • \(A(-3\sin 40^\circ, 3\cos 40^\circ, 0) = (-1.928\text{ ft}, 2.298\text{ ft}, 0)\)
  • \(\mathbf{r}_{CA} = -1.928\mathbf{i} + 2.298\mathbf{j} - 4\mathbf{k}\text{ ft}, \quad |\mathbf{r}_{CA}| = 5\text{ ft} \implies \mathbf{F}_1 = \{-38.57\mathbf{i} + 45.96\mathbf{j} - 80.00\mathbf{k}\}\text{ lb}\)
  • \(\mathbf{r}_{CB} = 4\mathbf{i} - 7\mathbf{j} - 4\mathbf{k}\text{ ft}, \quad |\mathbf{r}_{CB}| = 9\text{ ft} \implies \mathbf{F}_2 = \{36.00\mathbf{i} - 63.00\mathbf{j} - 36.00\mathbf{k}\}\text{ lb}\)
  • \(\mathbf{F}_R = \{-2.57\mathbf{i} - 17.04\mathbf{j} - 116.00\mathbf{k}\}\text{ lb}\)
  • \(F_R = 117.3\text{ lb}, \quad \alpha = 91.3^\circ, \quad \beta = 98.4^\circ, \quad \gamma = 171.6^\circ\)

2.6 Problem 6 (Lecture Problem 10)

The tower of height \(24\text{ m}\) at \(D(0, 0, 24\text{ m})\) is held in place by three cables anchored at \(A(x, y, 0)\), \(B(-6\text{ m}, 4\text{ m}, 0)\), and \(C(16\text{ m}, -18\text{ m}, 0)\) with forces \(F_{DA} = 400\text{ N}\), \(F_{DB} = 800\text{ N}\), and \(F_{DC} = 600\text{ N}\)[cite: 22]. Taking \(x = 20\text{ m}\) and \(y = 15\text{ m}\), determine the magnitude and coordinate direction angles \(\alpha, \beta, \gamma\) of the resultant force[cite: 22].

TipSolution Key — Problem 6 (Lecture Problem 10)
  • \(\mathbf{r}_{DA} = 20\mathbf{i} + 15\mathbf{j} - 24\mathbf{k}\text{ m}, \quad |\mathbf{r}_{DA}| = \sqrt{1201} = 34.655\text{ m} \implies \mathbf{F}_{DA} = \{230.85\mathbf{i} + 173.13\mathbf{j} - 277.01\mathbf{k}\}\text{ N}\)
  • \(\mathbf{r}_{DB} = -6\mathbf{i} + 4\mathbf{j} - 24\mathbf{k}\text{ m}, \quad |\mathbf{r}_{DB}| = \sqrt{628} = 25.060\text{ m} \implies \mathbf{F}_{DB} = \{-191.54\mathbf{i} + 127.69\mathbf{j} - 766.16\mathbf{k}\}\text{ N}\)
  • \(\mathbf{r}_{DC} = 16\mathbf{i} - 18\mathbf{j} - 24\mathbf{k}\text{ m}, \quad |\mathbf{r}_{DC}| = 34\text{ m} \implies \mathbf{F}_{DC} = \{282.35\mathbf{i} - 317.65\mathbf{j} - 423.53\mathbf{k}\}\text{ N}\)
  • \(\mathbf{F}_R = \{321.66\mathbf{i} - 16.82\mathbf{j} - 1466.70\mathbf{k}\}\text{ N}\)
  • \(F_R = 1502\text{ N} \approx 1.50\text{ kN}, \quad \alpha = 77.6^\circ, \quad \beta = 90.6^\circ, \quad \gamma = 167.6^\circ\)
